# Enterprise AI Portfolio — Workflow Economics Framework

An interactive board-level capital allocation framework for enterprise AI portfolios.

## Purpose

This framework helps executives sequence AI investment across workflow economics, ROIC opportunity, risk, and readiness.

It includes five interactive views:

- Capital thesis
- Portfolio map
- ROIC opportunity
- Workflow economics
- Board readiness

## Core thesis

Enterprise AI value is not created by deploying AI broadly. Value is created when specific workflows are redesigned, governed, measured, and sequenced against financial return and operational risk.
